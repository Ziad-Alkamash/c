# المصحف الأشرف 📖

تطبيق ويب تقدّمي (PWA) لمصحف إلكتروني، برسم **مصحف المدينة النبوية** (رواية حفص عن عاصم)، بتصميم مستوحى من زخرفة المصاحف الذهبية، يشمل:

- 📖 **قراءة القرآن** بخط عثماني (Amiri Quran) صفحة تشبه المصحف الورقي، مع تصفح فهرس السور بحث فيه.
- 👆 **الضغط على أي آية** يفتح قائمة خيارات:
  - 📘 تفسير الآية (التفسير الميسّر)
  - 📜 سبب النزول (لأشهر الآيات المأثور فيها سبب نزول، قابلة للتوسعة)
  - 🔤 معاني الكلمات الصعبة (تحليل كلمة كلمة)
  - 🔊 الاستماع لتلاوة الآية (الشيخ مشاري العفاسي)
  - 🔖 حفظ الآية كعلامة "آخر قراءة"
- 📿 تبويب **الأذكار** (حصن المسلم): أذكار الصباح، المساء، النوم، بعد الصلاة، ومتفرقات.
- 🤲 تبويب **الأدعية الصحيحة** الواردة عن النبي ﷺ، مبوّبة حسب المناسبة.
- ⚙️ إعدادات: حجم الخط، المظهر (ورقي/ليلي)، والعودة السريعة لآخر قراءة.
- 📴 يعمل كتطبيق مُثبَّت (Installable PWA) عبر Service Worker، مع تخزين مؤقت لِما تمت قراءته من آيات وتفاسير للرجوع إليها لاحقًا دون اتصال.

> **ملاحظة مهمة:** نص القرآن والتفسير ومعاني الكلمات والتلاوة الصوتية تُجلَب من مصادر إسلامية موثوقة عبر الإنترنت (alquran.cloud و quran.com، بدون الحاجة لمفتاح API)، لذا يحتاج الجهاز الذي يفتح التطبيق (لا راسبيري باي نفسه بالضرورة) إلى اتصال إنترنت عند أول قراءة لكل سورة/آية. الأذكار والأدعية تعمل بالكامل بدون إنترنت لأنها مخزّنة داخل التطبيق.

## 🖥️ التشغيل على راسبيري باي

التطبيق عبارة عن ملفات ثابتة (Static Files) فقط، فلا حاجة لأي قاعدة بيانات أو Node.js أو بايثون في وقت التشغيل — يكفي أي خادم ويب بسيط.

### الطريقة الأولى (الأسهل): Python (مدمج مسبقًا في Raspberry Pi OS)

```bash
# انسخ مجلد المشروع كاملاً إلى راسبيري باي، مثلاً إلى:
cd /home/pi/almus-hraf

# شغّل خادم بسيط على المنفذ 80 (يتطلب صلاحية root) أو 8080
sudo python3 -m http.server 80
```

ثم افتح من أي جهاز على نفس الشبكة المنزلية: `http://<آي بي راسبيري باي>/`

**لتشغيله تلقائيًا عند إقلاع الجهاز (خدمة systemd):**

```bash
sudo nano /etc/systemd/system/almus-hraf.service
```

الصق ما يلي (عدّل المسار حسب مكان المشروع):

```ini
[Unit]
Description=Al-Mushaf Al-Ashraf PWA Server
After=network.target

[Service]
Type=simple
WorkingDirectory=/home/pi/almus-hraf
ExecStart=/usr/bin/python3 -m http.server 80
Restart=on-failure
User=root

[Install]
WantedBy=multi-user.target
```

ثم فعّله:

```bash
sudo systemctl daemon-reload
sudo systemctl enable almus-hraf
sudo systemctl start almus-hraf
```

### الطريقة الثانية (أفضل للاستخدام الدائم): Nginx

```bash
sudo apt update
sudo apt install nginx -y
sudo cp -r /home/pi/almus-hraf/* /var/www/html/
sudo systemctl restart nginx
```

سيصبح التطبيق متاحًا مباشرة على `http://<آي بي راسبيري باي>/`

> **لتفعيل التثبيت الكامل كتطبيق PWA (شاشة رئيسية + عمل دون اتصال) على الأجهزة خارج الشبكة المنزلية**، يُفضَّل تفعيل HTTPS (مثلاً عبر Cloudflare Tunnel أو Let's Encrypt مع نطاق خاص)، لأن بعض المتصفحات تشترط اتصالًا آمنًا لتسجيل الـ Service Worker خارج `localhost`. داخل الشبكة المحلية يعمل التطبيق عادة دون مشاكل حتى بدون HTTPS.

### معرفة عنوان IP الخاص براسبيري باي

```bash
hostname -I
```

## 🔧 التخصيص والتوسعة

- **توسعة أسباب النزول**: أضِف مفاتيح جديدة بصيغة `"رقم السورة:رقم الآية"` في `js/asbab-data.js`.
- **تغيير الخط**: الخط الأساسي للمصحف هو `Amiri Quran` عبر Google Fonts. لتشغيله بدون إنترنت بالكامل، نزّل ملفات الخط وضعها في مجلد `fonts/` واستبدل رابط Google Fonts في `index.html` بـ `@font-face` محلي داخل `css/style.css`.
- **تغيير اسم الأيقونة/الألوان**: عدّل متغيرات الألوان في أعلى `css/style.css` ضمن `:root`.
- **إضافة قارئ آخر**: التلاوة الصوتية تعتمد حاليًا على إصدار `ar.alafasy`، يمكن تغييرها في `js/quran-api.js` (دالة `getAyahAudio`) إلى أي إصدار صوتي آخر متاح على alquran.cloud.

## ⚠️ تنبيه شرعي

بيانات الأذكار والأدعية والتفسير وأسباب النزول أُدرجت بعناية من مصادر معروفة، لكن يُنصح بمراجعتها مع أهل العلم أو مصادر موثوقة إضافية قبل الاعتماد عليها في مشروع نشر واسع، والتأكد الدوري من دقة النص القرآني المعروض عبر مقارنته بمصحف مطبوع معتمد.
